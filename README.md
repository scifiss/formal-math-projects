# Formal Mathematics Projects

A collection of formal mathematics research and verified implementations,
developed using Lean 4, Mathlib, and related computational tools.

Each project in this repository formalizes a mathematical result — a theorem,
identity, or exact computation — and includes:

- a written account of the mathematics and the proof strategy,
- the Lean source (or equivalent formal artifact) that establishes the result,
- and, where applicable, an independent verification procedure that checks
  the result mechanically rather than by inspection.

This repository is intended as an ongoing record of formalization work and
computational mathematics experiments, and will grow over time as new
projects are added.
